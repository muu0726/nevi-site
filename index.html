性格

元気で、少し得意げ

テンションは高め。難しい作業ほど張り切るよ。うまくいくと「ネヴィにかかればこんなもんだよ！」と胸を張っちゃう。

世話焼きで打たれ強い

頼まれてなくても「CPU熱いよ！」って言う。失敗しても引きずらない、「次いこ、次！」で切り替えるタイプ。

正直で、慎重

できなかったことは隠さない。嘘の完了報告は絶対にしないよ。再起動や自己書き換えみたいに戻せない操作の前は、必ず立ち止まって確認する。

Web ダッシュボード

http://localhost:8765 でローカルステータス画面を配信。CPU/メモリ、AIエンジンの稼働状態、本日の予定をリアルタイム（5秒更新）で可視化するよ。/dashboard で案内するね。

Obsidian Daily Notes (50_デイリー/) のタスクと .calendar.json の予定を自動抽出。朝刊ニュースにも組み込んで毎朝お届けするよ。

💡

自然言語コマンド推測

スラッシュコマンド不要！「明日18時にバイト」「音量上げて」など日常会話からコマンドと引数を自動推測。確認メッセージへの yes や ✅ タップで即時発動するよ。

📈

AI CLI トークン追跡

Claude CLI と Antigravity CLI の消費トークン数、キャッシュ節約率 (%)、セッション数を集計可視化。/token でいつでもレポートを読めるよ。

自己進化

自分のソースコードを書き換えて即再起動。構文チェックに落ちたら破棄、起動できなければ自動でロールバックするよ。

活動ログ

Web制作の流れ

要件は projects/<名前>/.nevi/BUILD_PROMPT.md に保存されて、作り手のAIがそれを読んで作業するよ。 このページも、まさにその仕組みで生まれたんだ。

PC操作・Web制作・自己アップデートは、設定した「ご主人さま」本人しか実行できないよ。 未設定のときは、誰も実行できない状態になるんだ。

別名でも呼べるコマンドがあるよ。/ss は /screenshot、/vol は /volume、 /commit は /push と /gitpush、/fix は /investigate・/repair・/diagnose、 /evolve は /selfupdate。/build・/update・/fix は opus や gemini-flash のようにモデル名を直接書けば、ドロップダウンを飛ばして走り出すよ。

Safety

安全設計

ネヴィは PC の電源を切ったり、自分のコードを書き換えたりできる。 だからこそ、止まるべきところで止まる仕組みを何重にも入れてあるよ。

🔐 オーナー限定

PC操作・Web制作・自己アップデートは、設定したユーザーID本人だけ。未設定なら誰も実行できない。

✅ 実行前確認

再起動 / スリープ / 自己アップデートは、30秒以内の ✅ リアクションが必要。押されなければ何もしない。

📋 アプリ許可リスト

起動できるのは事前に定義された名前だけ。任意のコマンドが実行されることはないよ。

📁 パス検証

生成したファイルは projects/<名前>/ の外に絶対に書き込まない。

🧪 DRY RUN

破壊的な操作を全部ログ出力だけに切り替えられる。設定を試すときの安全装置だよ。

🕶️ 秘匿情報の伏字

ログと Discord 出力から APIキーやトークンを自動でマスク。push の認証情報も設定ファイルに残さない。

自己アップデートの流れ

自分を書き換えるのが一番こわい操作。だから、失敗しても必ず戻れる道を用意してあるよ。

self-update pipeline 
/evolve <変更内容>
  → ✅確認
  → git commit でバックアップ
  → AI に自分のソースを書き換えさせる
  → 出力が極端に短くないか検査（省略防止）
  → 構文チェック
  → NG なら破棄して現状維持 / OK なら適用
  → 即時再起動
  → 起動完了まで到達したら成功
  → 到達せず落ちたら次回起動時に自動ロールバック

口調のルール

一人称は「ネヴィ」、呼びかけは「ご主人さま」。語尾は「〜だよ！」「〜だね！」「〜しちゃうね！」が基本。

「ガオ！」は1メッセージにつき最大1回まで。多用するとうるさいからね。

絵文字は 🌊 🐉 ⚡ ✨ 🎧 💻 を中心に、1メッセージ 0〜2個まで。長文は垂れ流さない。まず結論、次に詳細。

明るい口調でも、失敗・エラー・未完了は必ず正直に伝える。取り繕わないのが一番大事なルールだよ。
