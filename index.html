ネヴィって、だれ？

性格

元気で、少し得意げ

テンションは高め。難しい作業ほど張り切るよ。うまくいくと「ネヴィにかかればこんなもんだよ！」と胸を張っちゃう。

世話焼きで打たれ強い

頼まれてなくても「CPU熱いよ！」って言う。失敗しても引きずらない、「次いこ、次！」で切り替えるタイプ。

正直で、慎重

できなかったことは隠さない。嘘の完了報告は絶対にしないよ。再起動や自己書き換えみたいに戻せない操作の前は、必ず立ち止まって確認する。

Getting Started

はじめかた

用意するのは Windows 10 / 11 と Python 3.13 以上、それに Discord Bot ひとつ。あとは順番にやるだけだよ。

  1. Discord Bot を作って招待する

    Discord Developer Portal で Bot を作って、トークンを取得。 MESSAGE CONTENT INTENT を必ず ON にしてね。これを忘れると会話に反応しないよ。

    招待URLの SCOPES には bot と applications.commands の 両方が必要。片方だけだと / コマンドが出てこないんだ。

  2. 自分のユーザーIDを調べる

    Discord の 設定 → 詳細設定 → 開発者モード を ON にして、自分のアイコンを右クリック → ユーザーIDをコピー。 このIDの人が「ご主人さま」になるよ。

  3. .env を作る

    テンプレートをコピーして値を埋める。最低限この2つがあれば起動するよ。

    DISCORD_BOT_TOKEN=（手順1でコピーしたトークン）
OWNER_USER_ID=（手順2でコピーした自分のID）

    あとのキーは使いたい機能に応じて足すだけ。未設定の機能は自動で無効になるから、 いきなり全部そろえなくても大丈夫。

  4. 起動する

    起動用のバッチをダブルクリック。初回だけ仮想環境の作成と依存インストールが走るよ（数分）。 異常終了しても5秒後に自動で復帰するから、置いておけば勝手に立ち直る。

    初回は DRY RUN モードを推奨。 再起動・スリープ・デプロイ・自己書き換えが「ログ出力だけ」になるから、安心して動作確認できるよ。

Anthropic の APIキーは必須じゃないよ。 Web制作と自己アップデートは、ローカルの claude CLI がログイン済みなら、 そのサブスクリプションのまま動くんだ。

Safety

安全設計

ネヴィは PC の電源を切ったり、自分のコードを書き換えたりできる。 だからこそ、止まるべきところで止まる仕組みを何重にも入れてあるよ。

🔐 オーナー限定

PC操作・Web制作・自己アップデートは、設定したユーザーID本人だけ。未設定なら誰も実行できない。

✅ 実行前確認

再起動 / スリープ / 自己アップデートは、30秒以内の ✅ リアクションが必要。押されなければ何もしない。

📋 アプリ許可リスト

起動できるのは事前に定義された名前だけ。任意のコマンドが実行されることはないよ。

📁 パス検証

生成したファイルは projects/<名前>/ の外に絶対に書き込まない。

🧪 DRY RUN

破壊的な操作を全部ログ出力だけに切り替えられる。設定を試すときの安全装置だよ。

🕶️ 秘匿情報の伏字

ログと Discord 出力から APIキーやトークンを自動でマスク。push の認証情報も設定ファイルに残さない。

自己アップデートの流れ

自分を書き換えるのが一番こわい操作。だから、失敗しても必ず戻れる道を用意してあるよ。

self-update pipeline 
/evolve <変更内容>
  → ✅確認
  → git commit でバックアップ
  → AI に自分のソースを書き換えさせる
  → 出力が極端に短くないか検査（省略防止）
  → 構文チェック
  → NG なら破棄して現状維持 / OK なら適用
  → 即時再起動
  → 起動完了まで到達したら成功
  → 到達せず落ちたら次回起動時に自動ロールバック

口調のルール

一人称は「ネヴィ」、呼びかけは「ご主人さま」。語尾は「〜だよ！」「〜だね！」「〜しちゃうね！」が基本。

「ガオ！」は1メッセージにつき最大1回まで。多用するとうるさいからね。

絵文字は 🌊 🐉 ⚡ ✨ を中心に、1メッセージ 0〜2個まで。長文は垂れ流さない。まず結論、次に詳細。

明るい口調でも、失敗・エラー・未完了は必ず正直に伝える。取り繕わないのが一番大事なルールだよ。
